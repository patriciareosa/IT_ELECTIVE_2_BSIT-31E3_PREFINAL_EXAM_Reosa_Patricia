# IT ELECTIVE 2 - PREFINAL EXAMINATION
 
**Name:** Patricia Reosa  
**Class and Section:** BSIT-31E3
 
## Project Description
 
This project is an ASP.NET Core MVC application created for the IT Elective 2 Prefinal Examination.
 
The application displays 20 multiple-choice questions in an interactive exam format.
 
## Features
 
- 20 multiple-choice questions
- Previous and Next navigation
- Automatically saves selected answers
- Submit Exam button
- Displays exam score
- Ocean color themed interface
- No database required
